# 降幂公式

1. $sin2x=\frac{1−cos(2x)}{2}$

2. $\cos^2 x = \frac{1 + \cos(2x)}{2}$

3. $\sin x \cos x = \frac{1}{2} \sin(2x)$



# 积化和差公式

1. $sinAsinB=\frac{1}{2}[cos(A−B)−cos(A+B)]$

2. $cosAcosB=\frac{1}{2}[cos(A−B)+cos(A+B)]$

3. $sinAcosB=\frac{1}{2}[sin(A+B)+sin(A−B)]$
4. $cosAsinB=\frac{1}{2}[sin(A+B)-sin(A−B)]$
