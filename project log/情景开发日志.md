# 初步实现

| 时间 | 2025/6/10                                                    |
| ---- | ------------------------------------------------------------ |
| 功能 | 1. 添加游离点，使其在画布中自由移动<br/>2. 点击按钮时，能够指引追踪目标点位置 |
| 缺陷 | 未跟随地图缩放自适应                                         |

> [!warning]
>
> 针对功能一，有以下两点注意：
> 1. 控制好游离的范围，边界为总画布减去面板的范围，当游离点碰到边界时，要设置反弹
> 1. 当界面变化时，需要重新计算范围

:sparkles:检测和反弹实现

```vue
if (target.x <= mapBounds.value.left || target.x >= mapBounds.value.right) {
    target.vx = -target.vx
    target.x = Math.max(mapBounds.value.left, Math.min(mapBounds.value.right, target.x))
}

if (target.y <= mapBounds.value.top || target.y >= mapBounds.value.bottom) {
    target.vy = -target.vy
    target.y = Math.max(mapBounds.value.top, Math.min(mapBounds.value.bottom, target.y))
}
```
